# Admin Dashboard

A responsive Admin Dashboard built using HTML, CSS, and JavaScript. This project includes a sidebar navigation menu, analytics cards, a recent orders table, dark mode support, and a responsive layout for mobile devices.

## Tech Stack

- HTML
- CSS
- JavaScript

## Features

- Responsive Layout
- Dark Mode
- Sidebar Navigation
- Analytics Dashboard
- Recent Orders Table
